# Hexlands

Download **[Hexlands v0.6.0 for Windows](https://github.com/tweeeki/hexlands-releases/raw/main/v0.6.0/Hexlands_0.6.0_x64-setup.exe)** (about 5 MB), run it, and
start Hexlands from the Start menu.

Windows shows "Windows protected your PC" because the installer is not signed:
click **More info**, then **Run anyway**. Hexlands installs for your Windows user only, without administrator rights.

Hexlands updates itself: when a new version is out, its start page offers it. Everyone in a game needs the same
version. Each version keeps its own folder here.
